# IT23332980 - Assignment 1 (IT3040)

##  Project Description

This project tests the accuracy of a Sinhala transliteration system using Playwright automation.

##  Tested Application

https://www.pixelssuite.com/chat-translator

##  Technologies Used

* Python
* Playwright
* OpenPyXL

##  Setup Instructions

1. Install Python (3.11 or 3.12)

2. Install dependencies:

   ```bash
   pip install playwright openpyxl
   playwright install
   ```

3. Run the script:

   ```bash
   python test_automation.py --excel "IT23332980_Assignment 1 - Test cases.xlsx" --url "https://www.pixelssuite.com/chat-translator"
   ```

##  Test Cases

* 50 Negative Test Cases
* Covers all 24 Singlish input types
